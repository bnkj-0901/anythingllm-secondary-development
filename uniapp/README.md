# 企业 AI 助手 · 用户端 v1

基于 uni-app、Vue 3 和 Wot Design Uni。H5 与微信小程序共用 `/api/enterprise` 的真实登录、知识和问答 API。

## 运行

先执行数据库初始化，创建首位顶级管理员，再启动仓库内的 server 与 collector。顶级管理员在网页平台端开通企业，企业管理员管理企业用户，顶级管理员维护模型与连接。小程序登录页可直接注册当前企业普通用户，注册后立即生效并登录；微信授权登录尚未接通。

```powershell
cd uniapp
yarn dev:h5
yarn dev:mp-weixin
```

H5 默认监听 5173，企业入口例如 `http://acme.localhost:5173`；微信开发构建位于 `dist/dev/mp-weixin`。不要同时运行两个指向同一输出目录的小程序编译进程。

每个租户的小程序在构建或部署前通过 `VITE_API_BASE` 固定企业 API 地址，例如 `https://acme.saas.example.com/api`，配置方式见 `.env.example`。开发者工具可配置 `http://acme.localhost:3001/api`。小程序缺少有效配置时停止请求并提示联系管理员。H5 未配置该值或配置为 `/api` 时使用当前页面域名，经 Vite 代理保留 Host。真机必须有可达的企业 HTTPS 域名，微信正式环境需配置 request 与 uploadFile 合法域名；裸 IP 和平台域名不能确定企业身份。

启动时自动连接预配置地址并读取 `/status`，用户只填写用户名和密码；登录调用 `POST /api/enterprise/login`，注册调用 `POST /api/enterprise/register`，正文仅为 `{ username, password }`。注册页校验确认密码，成功后提示保存或复制一次性恢复码；密码和恢复码不持久化。企业身份由服务端根据访问域名和受信代理信息解析。客户端不提供地址输入或切换企业操作，旧 `ep_tenant_endpoint` 缓存不会覆盖部署配置。

小程序只接受 `identity: "tenant"` 的企业身份，企业角色为 `admin` 或 `user`，不提供平台登录入口。会话包含 `identity`、`user`、`tenant`、`role`、`token` 和固定配置的 `endpoint`，登录后显示企业名称与地址。登录凭据保存在 `ep_token`、`ep_session`，启动时通过同一企业地址的 `/me` 重新验证；部署地址变更后清除旧凭据。退出和 401 会清除凭据、取消未完成请求，旧版、其他地址或平台身份缓存也会清除。

## 当前功能

- **知识资料**：创建公有或私有知识库；公有库变更提交管理员审批，私有库直接维护；按范围、知识库和关键词筛选；上传文件或自然语言文字；查看当前正文、编辑、删除、失败重试；自动轮询处理中的资料。
- **问答检索**：默认检索当前用户全部获授权知识库，会话本身不绑定知识库；创建和读取个人对话、提问、删除对话；显示等待状态、服务端错误和参考来源。点“查看当前原文”会重新请求资料详情，由服务端再次检查权限。
- **身份与隔离**：显示实际租户和账号。知识库独立于创建人；租户授权表示企业全员可读写，用户授权表示指定用户可读写。企业管理员不自动取得私有知识权限；顶级管理员可在网页管理端读取全部企业内容。所有授权由服务端执行。

问答使用服务端 SSE 事件：H5 通过 fetch 流读取，微信通过 `uni.request` 的 `enableChunked` 读取，支持跨分片的中文和 emoji 解码。生成片段仅为预览，只有收到有效最终事件并完整结束后才显示正式回答及来源；取消、失败或连接截断会清空未完成预览。停止按钮只取消当前消息，不取消知识列表等其他请求；退出或页面销毁会取消旧会话请求。模型和向量服务配置在网页后台管理，ERP 业务入口延期。通用 Agent/MCP 与原聊天能力在网页中按现身份执行，ERP 业务接入延期。页面没有本地模拟答案，模型未配置或服务不可用时显示真实错误。

上传格式及大小上限读取企业 API `GET /file-types`，文件选择器、提示和本地校验共用该返回值，不在用户端维护另一份固定格式清单；最终授权和文件检查由服务端执行。

`src/services/enterprise.mjs` 统一处理认证、知识和问答请求。当前用户入口不导入本地模拟资料、模拟回答或旧工作区接口；这些原源码和原测试仍保留在仓库中。

## 构建与检查

```powershell
yarn build:h5
yarn build:mp-weixin
node --experimental-default-type=module --test tests/*.test.mjs
```

微信发布构建位于 `dist/build/mp-weixin`。客户端用例覆盖固定地址配置、H5 同源、旧地址缓存隔离、配置变更登出、域名登录、会话恢复、迟到响应隔离、平台身份拒绝、401 清理、真实上传字段、来源重授权、SSE 分帧与 UTF-8 分片、独立消息取消和最终事件校验。页面保留桌面侧栏、手机双入口底栏、胶囊安全区与键盘高度适配；发布环境仍需核验分块响应、合法域名和软键盘效果。
