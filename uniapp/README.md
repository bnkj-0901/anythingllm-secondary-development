# 企业 AI 助手 · 页面原型

基于 uni-app、Vue 3 和 Wot Design Uni 的交互原型。当前使用本地 Mock 数据，无需启动 server、collector 或配置 API 凭据。

```powershell
cd uniapp
yarn dev:h5
```

浏览器访问 http://localhost:5173。

## 页面与交互

- **问答检索**：无工作区选择，默认检索全部公有知识与当前用户自己的私有知识；也可切换“仅公有”或“仅我的私有”。使用本地关键词匹配、模拟逐字回答和来源引用，支持查看当前来源原文、新建对话、个人历史和停止生成。
- **知识资料**：按“全部 / 公有知识 / 我的私有”筛选，再按知识分类查看；支持搜索、详情、编辑、删除、选择本地文件和录入文字。新增资料默认选择私有，可主动改为公有。文字可编辑内容并参与本地检索；文件只保存名称和大小，不上传、不解析，可修改名称。
- **ERP 助手**：模拟查询商品库存、按客户或单号查询订单；创建销售订单经过补全、校验、核对和确认，再返回 DEMO 编号。不会连接真实 ERP。

用户端仅保留以上三个入口。模型、API、成员与权限等管理配置属于后台，后续单独设计，本轮不展开。

## 公私规则与演示身份

| 知识范围 | 查看与检索 | 上传、编辑、删除资料 |
| --- | --- | --- |
| 公有 | 平台内所有已登录用户 | 平台内所有已登录用户，包括维护他人上传的资料 |
| 私有 | 仅所属用户本人 | 仅所属用户本人 |

管理员没有读取或维护他人私有知识的例外。知识分类用于组织资料，公私范围决定谁能访问；两者不等于 Workspace，也不绑定聊天线程。每个用户的问答历史独立，ERP 业务权限单独校验。

点击顶部“演示 · 用户名”或侧栏个人信息，可切换林晓（管理员）、陈亦、周宁。三人共享产品资料、业务流程、人事制度中的公有资料，各自拥有不同的私有笔记和聊天记录。切换身份会清空当前输入与临时业务状态，并将检索范围恢复为“全部可访问”。这只是演示身份切换，没有真实登录。

资料、当前演示身份和个人问答历史保存在本机，存储键为 `enterprise-ai-preview-v2`。旧版 `enterprise-ai-preview-v1` 不会自动迁移，也不会被清除。ERP 模拟结果仅在当前组件内保留，刷新或切换身份后重置。

所有演示身份的数据都位于同一个客户端存储中。页面筛选和本地权限检查用于验证交互规则，不构成生产环境的数据隔离；真实系统必须在服务端统一校验检索、原文件读取及资料变更请求。

`src/services/demo.js` 集中维护示例资料与本地检索逻辑。当前入口没有导入旧版 `services/chat.js` 或 `ChatUpload.vue`，它们暂存为后续接口适配参考，不参与本次页面运行。

本原型没有调用 LLM、Embedding、向量库或 MCP。示例文件预置的文字用于演示来源，新选择的文件没有可检索正文。当前用户端的初步设想、交互示意及待核对事项见 [用户端初步设想](docs/product-architecture.md)；该文档不代表已定稿的产品架构或技术方案。
